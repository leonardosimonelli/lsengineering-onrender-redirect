GUIDA ALLA CONSEGNA

Installazione REVERSE M13 2D

Scarica il file ZIP completo dalla pagina aperta dopo l’acquisto. Se hai perso il collegamento, recupera il tuo acquisto.

Windows

Salva lo ZIP sul computer personale, estrailo in una cartella e apri il file di avvio Windows presente nel pacchetto. Segui il manuale incluso: l’esatto nome del launcher può variare secondo la distribuzione.

Linux

Estrai il pacchetto nella tua home e consulta la documentazione di avvio Linux inclusa. Se contiene uno script .sh, usa il terminale per eseguirlo secondo le istruzioni fornite. Verifica che siano presenti le dipendenze richieste.

Download a tre parti

Le tre parti sono segmenti consecutivi del medesimo ZIP: vanno unite, non estratte singolarmente.

Windows, dal Prompt dei comandi nella cartella dei file:

copy /b REVERSE_M13_Multilingua.part01+REVERSE_M13_Multilingua.part02+REVERSE_M13_Multilingua.part03 REVERSE_M13_Multilingua.zip

Linux o macOS:

cat REVERSE_M13_Multilingua.part01 REVERSE_M13_Multilingua.part02 REVERSE_M13_Multilingua.part03 > REVERSE_M13_Multilingua.zip

Assistenza

In caso di problemi scrivi a LS Engineering, indicando sistema operativo e messaggio d’errore, senza inviare credenziali o dati della carta.
